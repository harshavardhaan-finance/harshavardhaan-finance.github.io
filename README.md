# Financial Analytics & Modeling Portfolio

Welcome to my portfolio website! This is a showcase of my financial modeling, business intelligence, and data analytics projects.

## About

I'm a financial analyst and modeling specialist with expertise in:

- **Financial Modeling**: DCF valuation, sensitivity analysis, integrated financial statements
- **Business Intelligence**: Power BI dashboards, KPI reporting, executive analytics
- **Data Analytics**: SQL analysis, working capital metrics, performance reporting
- **Project Finance**: Capital budgeting, debt financing, investment evaluation
